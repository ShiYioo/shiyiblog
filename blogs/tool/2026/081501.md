想实时变声然后输出到其他软件里（比如开黑、直播），这套方案亲测能用，配置也不算难。

## 📖 RVC 是什么

`RVC`（Retrieval-based Voice Conversion）是一个开源的 **AI 变声工具**，可以把你的声音实时转换成其他人的音色。

> 下载地址：<https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/releases>

下载的时候根据自己的显卡选版本：

| 显卡 | 选择 |
|------|------|
| N 卡，小于 50 系 | For Nvidia GPU users (\<50x0) |
| N 卡，50 系及以上 | For Nvidia GPU users (\>=50x0) |
| A 卡 / Intel 核显 | For AMD/Intel GPU users |

---

## 🎛️ 为什么还需要 Voicemeeter

光有 RVC 还不够，我们需要一个**虚拟声卡**把变声后的声音「接」出来，交给其他软件当麦克风用，这就要请出 `Voicemeeter` 了。

简单说：RVC 负责变声，Voicemeeter 负责把变完的声音虚拟成一个输入设备，两个配合才能闭环。

当然肯定还有其他方案，这里主要介绍 Voicemeeter 方案。

> 下载地址：<https://vb-audio.com/Voicemeeter/index.htm>

---

## 🛠️ 开始配置

### RVC 设置

启动 RVC UI 之后，设置输入输出：

- **输入**：选你的物理麦克风（我这里是 `麦克风 (Realtek(R) Audio)`）
- **输出**：选 `Voicemeeter Input (VB-Audio Voicemeeter VAIO)`

输入就是电脑阵列麦克风或者自己耳机的麦克风，反正是真实存在的物理设备，这不需要我多解释。

输出这里的 `Voicemeeter Input` 其实是 Voicemeeter 在 Windows 里注册的一个**虚拟扬声器**——对系统来说是输出，但对 Voicemeeter 来说是「输入」，因为声音从系统流进了 Voicemeeter。

> 更多详情：<http://voicemeeter.com.cn/post/36.html>

### Voicemeeter 设置

界面里有 **两个 Input** 和**一个 Virtual Input**，最右边的是观测器，可以选自己的设备进行试听。

::: warning
注意观测器试听会**占用设备**，测试完记得关掉。
:::

免费版只有 A 通道和 B 通道，点亮一个按钮会直接打开 A1A2 或者 B1B2，也就是**一个按钮打开两个**。怎么调成单个？我也不知道，好多英文我不想看，好多英文我好晕 🫠，可能大概是付费专属的。

各通道设置如下：

| 通道 | 设备选择 | ▶A | ▶B |
|------|----------|----|----|
| Stereo Input 1 | None（不选） | 灭 | 灭 |
| Stereo Input 2 | None（不选） | 灭 | 灭 |
| Virtual Input | 不用选（RVC 会自动把声音送进来） | 亮 | 亮 |

然后把右上角的 **A1** 设置为你的真实耳机。

### Windows 设置

最后去改一下 Windows 的声音设置：

- **输入（录制）默认设备** → `Voicemeeter Out B1`
- **输出（播放）默认设备** → 你的真实耳机

---

## ✅ 大功告成

再点击 RVC 的**开始转换**，变声后的声音就会送到其他软件上了，是不是很简单。

::: tip
整体思路就一句话：物理麦克风 → RVC 变声 → Voicemeeter 虚拟声卡 → 系统默认输入，其他软件直接用就行。
:::
