## 3. 扣子空间

国内最好用的云 agent，有什么用呢？用处多着呢：

- 📄 **写实现报告、修改文档格式** —— 谁会花几个小时在那里调整格式呀，这个在大学期间几乎是无敌的
- 📊 **生成流程图** —— 感觉也是可以的
- 📑 **生成 PPT** —— 可以导出为可修改的模式，支持二次修改
- 🛠️ **agent 小工具** —— 比如 agent 邮箱什么的
- 🎬 **生成视频** —— 可以导出为剪映格式

::: warning
目前生成视频有 bug，网页端渲染的视频和手机端渲染的音频不一样，不知道为什么，以手机端为主。
:::

还有一些更实用的功能：

- 📚 给他一大堆复习资料，让他出**考前总结**，非常 OK 的
- 🔍 **深度搜索** —— 这几天公司让我搜索资料来着，老板说要花不少时间，但是我一上午就给他搜集完了，信息可信度高，没有什么错误的地方，都是真实搜索
- 🚀 可以自己**部署项目**，提供域名展示等等等
- 💻 可以用积分换服务器的核数、内存、流量，还能换云电脑、云手机

::: tip
反正里面集成了非常多功能，感觉东西挺多的，还有些新东西我都没有用过，总之非常可以的，国内的云 agent 的 No.1

🔗 地址：<https://www.coze.cn/overview>
:::
