如果多个人想一起看电影，又想**电影同步**，又想**弹幕**，又想**语音聊天**，该怎么办？

很简单，用 `synctv` 就行。

## 📦 synctv 是什么

`synctv` 是一个**开源的同步观影服务**，支持多人同步播放视频、发弹幕、房间聊天，部署也非常简单。

> 地址：<https://github.com/synctv-org/synctv>

---

## 🛠️ 怎么用

这边说一下 Windows 吧（我用的是 Windows）。

首先去 GitHub 下载对应的二进制包，然后就可以开始输入命令了。

```bash
# 1. 查看版本
.\synctv-windows-amd64.exe version

# 2. 启动服务器（默认配置）
.\synctv-windows-amd64.exe server
```

首次启动 server 会在 `C:\Users\你的用户名\.synctv` 生成配置文件，并打印出默认管理员账号密码，**务必记下来**。

::: tip
默认 `root` 账号密码就是 `root` / `root`。
:::

### 启动方式

最简单（推荐先这样试）：

```bash
synctv-windows-amd64.exe server
```

自定义数据目录（不想放在 C 盘）：

```bash
synctv-windows-amd64.exe --data-dir "E:\synctv-data" server
```

这样就算是启动成功了。

## 👥 设置用户

还要记得为你的小伙伴或者对象设置一个用户哦，**加入房间是需要用户的**。

在后台管理里直接添加用户即可。

## 🎬 视频直链

可以添加**视频直链**，几乎所有网站的视频都能同步。

怎么找直链呢？一般有几个方式：

- 浏览器**开发者工具**（F12）→ Network 面板，筛选视频请求
- 用一些解析工具/网站提取直链
- 部分网盘（比如阿里云盘）分享出来的链接可以转成直链

::: warning
部分网站的直链有时效性，过期了需要重新获取。
:::
