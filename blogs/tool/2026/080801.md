## 📢 居然更新了

之前版本一直停在 **0.9.15**，还是 **2025 年**发布的，我还以为这项目凉了。

结果昨天直接跳到了 **1.0.0**，今天去看又发布了 **1.0.1**，速度有点离谱。

---

## 🔄 更新了什么

这次更新改动相当大，几乎算是重写了一波：

| 项目 | 之前 | 现在 |
|------|------|------|
| 界面 | Web UI | 跨平台应用（客户端） |
| 数据库 | SQLite | PostgreSQL + Redis |
| 服务端 | 二进制包直接运行 | Docker Compose 部署（纯后端） |
| 功能 | 基础功能 | 增加了很多新功能 |

::: warning
新功能虽然多，但 bug 也不少，目前体验下来还不太稳定。
:::

## 🛠️ 部署

部署过程嘛，大家看看文档应该就会了，很简单的。

> 文档地址：<https://docs.syncs.tv/install/docker-compose/>

::: warning
至于想在 **Windows** 上直接运行的话，只能用老版本的 Web 版了。
新版本想在 Windows 上玩，**必须得用 Docker Desktop**。
:::

---

## 📝 总结

`synctv` 这次更新算是从「小工具」往「正经服务」转型了，架构更重了（PostgreSQL + Redis），但也更强大了。

就是目前还不太稳定，建议大家**生产环境再等等**，自己折腾折腾倒是没问题 🎉
